8 · How we score it

  1. Daily: the sentinel's hourly summary now carries a 📐 forecast line — live equity vs the base-scenario band for that day, flagged when we run below p10 or above p90.
  2. Weekly: re-measure twin drag (live vs paper on same-mint trades). Drag >9pp for a week → the base scenario is falsified; execution work resumes before sizing grows.
  3. Cohort refresh: the smart-money study re-runs as wallet coverage grows past n=100 compound setups; thresholds (≥2 winner-rep, net ≥1) refit only on out-of-sample confirmation.
  4. Falsifiers: compound-cohort win rate <55% on the next 50 setups, or the inflow-edge spread collapsing under +5pp, invalidates the forecast — we say so and re-issue.
