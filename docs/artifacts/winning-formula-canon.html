IIThe Trading Lifecycle — every trade traces through these stages

Each stage names its owner, its knobs (config keys), and its audit trail. A trade that cannot be traced stage-by-stage through this pipeline is a defect by definition.

  1. DISCOVERY — the scout witnesses the market

    DexScreener/GT polling across venues; tokens table is the census. Latency measured 0.1m scout→candidate (not a bottleneck).

    Knobs: venue list, poll cadence · Surface: Pond Radar · Evidence: tokens.first_seen_at
  2. SAFETY — traps hard-block, flags inform

    Honeypot probe, mint/freeze authority, confirmed rug = refuse outright. Soft flags (LP-unlock, concentration, low holders) inform only — the risk-tier size multiplier is retired (72% vs 73% win: zero discrimination).

    Audit: safety_checks rows · fluxbeam trap filter is never softened
  3. WATCH — the recorder builds the trajectory

    Candidate ticks every poll; ref price fixed at first trusted read; peak sanity (liq ≥$1k, ≤3×/tick). This tape is the formula's raw material.

    Knobs: RECORDER_POLL_MS, RECORDER_WINDOW_MIN · Evidence: candidate_ticks
  4. TRIGGER — the SEAT (F2)

    Confirm aperture + boarding band + churn dead-zone + vertical-spike ceiling + snap bars per class. The sweetspot finder re-measures the band inside hard rails; blow-throughs go to the re-confirm retrace path (trough reclaim ≥15% ≤45m), never chased.

    Knobs: CONFIRM_MIN/MAX_WATCH_MIN, CONFIRM_MIN/MAX_MULT, CONFIRM_DEAD_BUYSHARE_*, CONFIRM_MAX_RISE_INTO_GATE, SWEETSPOT_* · Audit: entry_trigger, sweetspot_band · Surface: Sweetspot Radar
  5. ROUTING — the signature genome

    RISER / BASE / CLIMBER / MOON_* / RUG_RISK from trajectory shape; the genome owns the exit profile. RUG_RISK never trades.

    Evidence: candidate_outcomes.signature, stars · Surface: 🧬 chips everywhere
  6. ADMISSION — the CROWD (F1) and the gate stack

    Wallet-graph anti-gate (net ≤ −1 refused, both lanes) · crowd gate (winner-rep required below strong — canon says everywhere, pending model run) · inflow envelope (F3) · pool-depth floors · clone-wave · regime hysteresis · stars bar · winner-rep receiver bypasses · blocklist-with-funnel-waiver · DBC moon tickets (bounded seats).

    Knobs: LIVE_MIN_INFLOW, LIQ_INFLOW_STRONG, LIVE_MIN_ENTRY_LIQ(_SM)_USD, LIVE_MIN_STARS, LIVE_CLASS_BLOCKLIST, LIVE_DBC_TICKET_* · Audits: entry_wallet_antigate, entry_crowd_unknown_refused, live_buy_skipped, live_class_block_waived, live_dbc_ticket
  7. SIZING — compounding capital, regime range, conviction point

    Capital = base + realized (30s refresh) · policy sets frac range from close-count regime window · conviction stars pick the point · class multiplier · session tilt · texture tilt (F4, pending) · probes for measured-weak cohorts.

    Knobs: PAPER_BANKROLL_USD+realized, POSITION_FRAC_MIN/MAX, OFF_HOURS_SIZE_MULT, class size profiles · Retired: risk-tier multiplier
  8. ENTRY EXECUTION — the fastest honest horse

    2s entry scan · fires at size-known, parallel to paper bookkeeping · entry friction loop (venue failover, bounded slippage retry, chase guard) · mirror-freshness gate (never buy a move whose twin already exited) · stage clock on every live open.

    Knobs: TRADER_POLL_MS, LIVE_SLIPPAGE_BPS, ENTRY_MAX_SLIPPAGE_PCT · Audit: live_open.latencyMs, live_buy_retry
  9. MANAGEMENT — ride vs cut, with the pool as witness (F5)

    Trail arms at 1.2× · 65% gain-lock floor · class TP ladders (rug defense) · never-armed stop (8m grace, −25%, interim pending replay) · fire-sale escalation + sell venue failover · depth-continuation signal (canon, pending wiring): pool stalled at the crest → bank hard; pool filling → breathe.

    Knobs: PROFIT_LOCK_GAIN_LOCK, RUNNER_RATCHET_*, class tp0/tp1/tp2, NEVER_ARM_*, HARD_STOP_PCT(_THIN) · Surface: Position Command + lifecycle SVG

    profit_trail · take_profit_N · hard_stop · never_armed_stop · runner_timeout · stale_take · basket_harvest · dust_rug · live_unsellable · desync heals carry their sell's true reason. Atomic pool deaths are entry-selection losses by definition — no exit mechanism applies.
