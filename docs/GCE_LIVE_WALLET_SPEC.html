3 · Sizing — even tickets, adaptive basket

  • Regime-adaptive basket: aggregate deployment 1.5–5% of balance by adaptive-policy hostility, divided evenly across MANDATE_SLOTS (8) — one trade can never destroy a basket aae66cb. Terminal knobs: MANDATE_AGG_FRAC, PROBE_SLOT_FRAC (probe = .35 of slot).
  • Live mirror fraction: live receives paper's realized fraction against the wallet balance, floored at LIVE_MIN_POSITION_USD ($2.50) so fees never eat the ticket; capped ≤14%/position, ≤40% exposure, daily −$35, auto-kill −$32.
  • Band-weighted slot priority: when slots contend, strong inflow (≥1.30×) boards first, then winner-rep crowd, then rest — allocation follows measured ¢/$; geometry never moves 4f04bd5 (strong 9.4¢/$ vs 1.3¢/$, 3d).

5 · RPC architecture

  • Keyed primary: Helius mainnet via HELIUS_API_KEY + HELIUS_RPC_ENABLED — per-key rate limits; verified by authenticated getSlot before trust. Public endpoints demote to fallback pool.
  • Sells outrank telemetry: sentinel chain-ingest at 5m, deployer walker at 30m d08bbf0 — shared-RPC 429s once turned live sells into ~$20 of write-offs.
  • DPI-hardened transport: curl-fallback (resilientFetch/rpcConnection) everywhere — this host's DPI resets naked Node fetch.
  • ws telemetry (P1): one socket, accountSubscribe per open-position pool + armed candidates (cap 15, open book first) — lamports on bonding curves = the quote side of the pool, drain visible as the TX executes.

6 · The exit chain — one mechanism, end to end 64cf842

flowchart LR
  PEAK[peak crosses rung] --> RUNGS[peak-triggered TP rungs 0.7x fill guard]
  RUNGS --> MICRO[micro-TPs 2.5x..55x]
  MICRO --> RATCHET[milestone ratchet 0.7x of highest]
  RATCHET --> TRAIL[class trail and cover genome]
  DRAIN[ws drain ≥50%/30s] --> FAST[fastDrainExit — event-speed cut]
  TRAIL --> CLOSE[close]
  FAST --> CLOSE
  • Peak-triggered rungs: a spike through a rung between polls still banks (was the "7/10 winners, break-even curve" choke: rungless deaths ran a 2.4:1 loss asymmetry).
  • Bank floor: learned profiles may move rung prices, never sell less than the compiled genome's fractions d761e31 (Ferret: 45% banked vs 70% spec → 55% rode a 5.26× to zero).
  • Fast drain exit: pool SOL halves in 30s → sell fires off the ws event itself d268436. Proven: first two live drain cuts closed green against a measured −13/−16% legacy tail.
  • Retry escalation: backoff 2/2/5/10/20/40s with tolerance escalation; unsellable write-off only after ~14 minutes of exhausted routes.
  • Book-write integrity: a confirmed on-chain sell can never be re-reported as a failed sell — the close-patch verifies-then-retries the write only 110cca6 (BullPad/CALLOUT phantom losses).
