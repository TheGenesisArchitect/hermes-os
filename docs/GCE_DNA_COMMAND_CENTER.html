The DNA Panel as the platform's command center

July 25, 2026 · consolidation, not addition — the existing Position Command / DNA surface absorbs the scattered lookups · companion to the Foundation Spec and the P0–P4 Chain program
The metaphor is now literal. The formula is a genome (F1–F6). Each trade is a cell running it. The book is the organism. The market is the environment. Deployers are pathogens. The benchmark contract is the vitals monitor. The diagnosis agent is immune memory. A command center is that biology on one screen — every number already computed, every control already built, brought to where the operator is already looking.

Consolidation rule

This surface retires lookups instead of adding panels: the vitals absorb the checkpoint scorecards; the environment strip absorbs the hand-run funnel queries; the organism absorbs the per-trade forensics. One screen answers "are we winning, what's at risk, what's coming" — the three questions every checkpoint currently answers in prose.
